Where the source code of every program in this package comes from
==================================================================

The launcher (GPL-3.0-or-later)
  https://github.com/akitaonrails/rea-teknoparrot-sega-series
  (the source archive of each release is on its GitHub release page)

windowsarcadeloader (GPL-3.0-or-later): components/wal
  https://github.com/aderumier/windowsarcadeloader at commit
  4f42c6d86ddaaa9d2e4e8c21e0046bb3027b111d, with the launcher's patches/wal
  applied (in the launcher's source: patches/wal/*.patch).

GE-Proton (Wine and its components; LGPL-2.1 and others), Linux package only:
components/runner
  https://github.com/GloriousEggroll/proton-ge-custom/tree/GE-Proton11-13
  (release GE-Proton11-13, unmodified)

winetricks (LGPL-2.1), Linux package only: components/winetricks
  https://github.com/Winetricks/winetricks/tree/20260125 (unmodified)

SDL 2 (zlib)
  https://github.com/libsdl-org/SDL (release 2.32.10 on Windows; Debian
  bookworm's libsdl2 on Linux)

lindbergh-loader (CC BY-NC-SA 4.0), Linux package only: components/lindbergh
  https://github.com/lindbergh-loader/lindbergh-loader at commit
  0af606d845b70339c335785c0eba68b47b78df3c (unmodified); built with
  SDL 3.2.26, SDL_ttf 3.2.2, SDL_image 3.2.4 and FAudio 25.11 from their
  release tags, and Ubuntu 22.04's i386 libraries (source: the Ubuntu
  archive's source packages freeglut, gcc-3.3 (libstdc++5), libxmu, libxi,
  libglu, libxt, libsm, libice, libbsd, libmd, at the versions listed in
  licenses/lindbergh-libraries/VERSIONS.txt).
  libssl/libcrypto 0.9.7 (OpenSSL licence) and libopenal.so.0 (LGPL-2) come
  as binaries from lindbergh-loader's libs/ folder at the same commit; their
  sources: https://github.com/openssl/openssl (OpenSSL_0_9_7 branch) and
  the OpenAL library lindbergh-loader took them from; for a copy of either,
  open an issue at
  https://github.com/akitaonrails/rea-teknoparrot-sega-series/issues

Flycast 2.7 (GPL-2.0): components/flycast
  https://github.com/flyinghead/flycast/tree/v2.7. The Linux package holds
  its official AppImage flycast-x86_64-2.7.AppImage, unpacked, unmodified;
  the Windows package its official flycast-win64-2.7.zip's flycast.exe,
  unmodified. The libraries in
  components/flycast/usr/lib are the ones that AppImage carries, from the
  Ubuntu archive of the release's build (their source packages are in that
  archive); for a copy of any of them, open an issue at
  https://github.com/akitaonrails/rea-teknoparrot-sega-series/issues

xemu Chihiro fork (GPL-2.0): components/xemu
  https://github.com/Tovarichtch/xemu/tree/Playtest-v2. The Linux package
  holds its release AppImage xemu-0.8.134-406-g0d44d803b2-x86_64.AppImage,
  unpacked, unmodified; the Windows package its release
  xemu-0.8.134-406-g0d44d803b2-windows-x86_64.zip's xemu.exe, unmodified.
  For a copy of the source, open an issue at
  https://github.com/akitaonrails/rea-teknoparrot-sega-series/issues

Microsoft DirectX June 2010 redistributable, Linux package only:
  components/directx (Microsoft's licence, redistributable)
